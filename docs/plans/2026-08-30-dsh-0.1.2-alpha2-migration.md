### 1. 源码修改（共 2 处破坏 + 1 处声明，全部必做）

**① `src/index.ts` — 替换被移除的 `settingsNamespace`（对应影响表 #1，运行时致命）**

```ts
// 第 29 行，改前：

// 改后（类型仍需 Context merge，可保留 type-only import）：
import type {} from '@deepseek-ai/dsh-settings'

// 第 45 行，改前：

// 改后（alpha2 的 register 直接收 kebab-case 字符串，类型层由
// SettingsNamespaceInput<'ya-subagent'> 校验，运行时 parseSettingsNamespace 兜底）：
export const SETTINGS_NAMESPACE = 'ya-subagent'
```

### 4. 可选清理（不影响功能）

- `src/rpc.ts` 头注释「the RpcError code union is closed」在 alpha2 已过时（`ConnectionRpcFailure.code` 已放宽为 `string`，闭联合并移往 gateway 的 `RemoteError`），可顺手更新措辞。

- 远期可选优化：alpha2 读侧尊重 `ignorable: true` 后，`src/repair.ts` 理论上可从「物理删除行 + 重编号」改为「给 `ya-subagent/started` 行打标记」（改动更小、保留数据）。非本迁移必须，改动前建议先在测试会话验证（标**待人工确认**）。
